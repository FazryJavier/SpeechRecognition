          How it works & privacy

          • Your browser’s built-in Web Speech API turns audio into text. Chrome and Edge send the audio to their cloud speech service to do this.
          • Voxtab itself is a static page: no server, no account, no analytics. Settings, shortcuts and history stay in this browser’s local storage.
          • Only plain http(s) links are ever opened. Search text is URL-encoded.
          • If nothing opens, allow pop-ups for this page (look for the blocked icon in the address bar). Browsers block tabs opened without a click.
